# دردونه

همراه رایگان خانواده‌های ایرانی، از آمادگی ازدواج تا قصهٔ شب کودک. این مخزن صفحهٔ اول سایت است.

## جهان طراحی: «شب کرسی»

صفحه یک شب برفی زمستان است و قصهٔ امشب روی لحاف کرسی ساخته می‌شود.

- **رنگ‌ها:** روناس (قرمز لحاف)، نیلی شب، زعفرانی برای کنش اصلی، گردویی. کتان فقط در دوخت و متن می‌آید.
- **فونت‌ها:** لاله‌زار برای تیترها و وزیرمتن برای بقیه. هر دو از پکیج‌های Fontsource روی خود سایت میزبانی می‌شوند.
- **پس‌زمینه‌ها:** ویدیوهای حلقه‌ای بی‌درز، هر کدام ۸ ثانیه. از صحنهٔ سه‌بعدی کرسی (three.js) به‌صورت آفلاین رندر شده‌اند، پس سایت برای پخششان نیازی به WebGL ندارد.
- **پنل‌های لحافی:** کلاس `.quilt` با نوار بته‌جقه (`src/assets/boteh-band.svg`) و کوک دوخت.

## بخش‌ها

1. **قصه‌ساز (صفحهٔ اول):** اسم بچه و یکی از سه قهرمان را انتخاب می‌کنید و قصه بدون ثبت‌نام و روی همان دستگاه ساخته می‌شود.
2. **پرسش‌های سلامت:** سه مرحله (پیش از ازدواج، بارداری، نوزاد). همهٔ پاسخ‌ها «در انتظار بازبینی پزشک» علامت خورده‌اند.
3. **لالایی‌ها:** متن لالایی‌های قدیمی. صدای آن‌ها هنوز اضافه نشده است.
4. **بازبین‌ها:** جای نام‌ها خالی است و هیچ نام ساختگی در آن نیست.
5. **ثبت‌نام با موبایل:** ارقام فارسی و عربی و پیشوند ‎+98‎ را می‌پذیرد.

## اجرا

```bash
npm install
npm run dev
npm run build
```

برای اتصال فرم ثبت‌نام به سرور، آدرس API را در `VITE_SIGNUP_URL` بگذارید. فرم بدنهٔ ‎`{ "phone": "09xxxxxxxxx" }`‎ را با POST به این آدرس می‌فرستد. تا وقتی این متغیر خالی است، موفقیت ثبت‌نام شبیه‌سازی می‌شود.

## ویدیوهای پس‌زمینه

فایل‌ها در `public/video/` هستند. هر نما سه فایل دارد:

- `.webm` با کدک VP9
- `.mp4` با کدک H.264 و faststart
- `.webp` به‌عنوان تصویر ثابت (پوستر)

رفتار ویدیوها:

- فقط وقتی بخش مربوط دیده می‌شود دانلود و پخش می‌شوند.
- دکمهٔ «توقف تصاویر متحرک» در سرصفحه همه را متوقف می‌کند.
- با «کاهش حرکت» سیستم‌عامل یا حالت صرفه‌جویی داده، فقط تصویر ثابت نشان داده می‌شود.

برای رندر دوبارهٔ ویدیوها بعد از تغییر `scripts/korsi/korsi-scene.js`، به Playwright و ffmpeg نیاز دارید:

```bash
npm run dev -- --port 5199
npm run render:korsi
npm run render:korsi -- hero quilt
```

دستور دوم همهٔ نماها را رندر می‌کند و دستور سوم فقط نماهایی را که نام برده‌اید.

## دسترس‌پذیری

- راست‌به‌چپ، با کنتراست سطح AA.
- اهداف لمسی دست‌کم ۴۴ پیکسل.
- ناوبری کامل با صفحه‌کلید: زبانه‌های سلامت با کلیدهای جهت کار می‌کنند و فهرست موبایل تمرکز را در خود نگه می‌دارد و با Escape بسته می‌شود.
- پشتیبانی از `prefers-reduced-motion`.
