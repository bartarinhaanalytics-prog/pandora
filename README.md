# pandora

قالب وردپرس **Aramesh** — سایت دوره‌های روان‌شناسی (فارسی، RTL).

قالب کامل در پوشه [`aramesh/`](./aramesh) قرار دارد؛ راهنمای نصب و پیکربندی در
[`aramesh/README.md`](./aramesh/README.md) آمده است.

- Bootstrap 5 RTL + PHP 8، بدون وابستگی به Page Builder
- نوع‌محتوای `course`/`lesson`/`testimonial`، ورود با OTP، مالکیت و پیشرفت دوره،
  پخش‌کننده ویدیوی محافظت‌شده، دو مسیر ثبت‌نام (داخل/خارج ایران) و سئوی ساختاریافته
- ۱۸ صفحه/الگو مطابق بسته‌ی طراحی

**نصب:** پوشه `aramesh` را در `wp-content/themes/` بگذارید و از پیشخوان فعال کنید.
