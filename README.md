# دردونه

همراه رایگان خانواده‌های ایرانی، از آمادگی ازدواج تا قصهٔ شب کودک.

## جهان طراحی: «شب و ماه و ستاره»

- **آسمان زنده:** پشت کل صفحه یک آسمان شب است که در لحظه با WebGL رسم می‌شود (`src/sky/skyShader.js`). شامل ماه، سه لایه ستاره در عمق‌های مختلف، راه شیری، ابرهای نازک مهتابی و گاهی یک شهاب است. هیچ مدل سه‌بعدی، تصویر یا ویدیوی سنگینی لازم ندارد.
- **پیمایش سینمایی:** با پیمایش صفحه، دوربین از آسمان به سمت افق پایین می‌آید. ماه بالا می‌رود و از قاب بیرون می‌شود، ستاره‌ها با سرعت‌های متفاوت حرکت می‌کنند و در پایان صفحه شهر خفته با گنبدها، بادگیرها و پنجره‌های روشن (`src/sky/town.svg`) به افق می‌رسد.
- **رنگ‌ها:** نیلی شب برای زمینه، نور سرد مهتاب برای متن، و طلایی ستاره فقط برای کنش اصلی.
- **فونت‌ها:** لاله‌زار برای تیترها و وزیرمتن برای بقیه، هر دو روی خود سایت میزبانی می‌شوند.
- **حرکت:**
  - با «کاهش حرکت» سیستم‌عامل یا حالت صرفه‌جویی داده، آسمان ثابت است.
  - بدون WebGL، تصویر ثابت آسمان (`src/sky/sky-*.webp`) نشان داده می‌شود.
  - گوشی‌ها آسمان را با وضوح کمتر رسم می‌کنند تا باتری کمتری مصرف شود.

**دادهٔ کاربر:** تا راه‌اندازی سرور همه‌چیز در localStorage همین دستگاه می‌ماند (`src/lib/store.js`). فرم‌های تماس، پرسش بی‌نام و دعوت همسر به `VITE_API_URL` (مسیرهای `/contact`، `/questions` و `/partner/invite`) فرستاده می‌شوند. اگر این متغیر خالی باشد، صفحه صادقانه می‌گوید که چیزی فرستاده نشد.

**محتوا:** مقاله‌ها (`src/data/articles.js`)، پرسش‌ها (`src/data/qa.js`)، ۴۰ هفتهٔ بارداری (`src/data/pregnancy.js`)، جدول واکسن، مرجع رشد، نیاز خواب و پیام‌های روزانه (`src/data/tools.js`) و قصه‌های آماده (`src/data/readyStories.js`) پیش‌نویس‌اند و برچسب «هنوز بازبینی نشده» دارند تا پزشک بازبینی کند. نام پزشک، نظر کاربر یا آمار ساختگی در سایت نیست.

## اجرا

```bash
npm install
npm run dev
npm run build
```

برای اتصال فرم ثبت‌نام به سرور، آدرس API را در `VITE_SIGNUP_URL` بگذارید. فرم بدنهٔ ‎`{ "phone": "09xxxxxxxxx" }`‎ را با POST به این آدرس می‌فرستد. تا وقتی این متغیر خالی است، موفقیت ثبت‌نام شبیه‌سازی می‌شود.

## ابزارهای آسمان

- **پیش‌نمایش:** `scripts/sky/still.html?t=3&s=0` روی سرور dev یک فریم ثابت از آسمان رسم می‌کند. `t` زمان به ثانیه و `s` میزان پیمایش (۰ تا ۱) است. تصویرهای ثابت از همین صفحه گرفته شده‌اند.
- **شهر افق:** با `python3 scripts/sky/town.py` دوباره ساخته می‌شود.

## دسترس‌پذیری

- راست‌به‌چپ، با کنتراست سطح AA.
- اهداف لمسی دست‌کم ۴۴ پیکسل.
- ناوبری کامل با صفحه‌کلید: زبانه‌های سلامت با کلیدهای جهت کار می‌کنند و فهرست موبایل تمرکز را در خود نگه می‌دارد و با Escape بسته می‌شود.
- پشتیبانی از `prefers-reduced-motion`.
