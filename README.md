# سایت دکتر نیلوفر احمدی

لندینگ‌پیج ریسپانسیو (HTML + CSS + کمی جاوااسکریپت) برای معرفی و فروش دوره‌های روانشناسی.

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید؛ هیچ ابزار بیلد یا وابستگی‌ای لازم نیست.

## ساختار

```
index.html        ساختار کامل صفحه (RTL، زبان فارسی)
css/styles.css    استایل‌ها + بریک‌پوینت‌های ریسپانسیو
js/main.js        منوی موبایل، اسلایدر نظرات، آکاردئون سوالات
assets/img/       تصاویر (فعلاً پلیس‌هولدرهای SVG)
```

## بخش‌های صفحه

هدر چسبان ← هیرو ← نوار ویژگی‌ها ← درباره من ← دوره‌ها ← موضوعات ←
چرا متفاوت‌اند ← مراحل شروع ← بنر تلگرام ← نظرات ← مقالات ← خبرنامه ←
سوالات متداول ← دعوت پایانی ← فوتر.

## ریسپانسیو

| بریک‌پوینت | تغییرات اصلی |
|---|---|
| `≤1100px` | نوار ویژگی‌ها دو ستونه، فشرده‌شدن منو |
| `≤1024px` | منوی کشویی موبایل، هیرو و درباره تک‌ستونه، کارت‌ها ۲ ستونه، اسلایدر با کشیدن انگشت |
| `≤768px` | همه‌ی گریدها تک‌ستونه، فرم‌ها و دکمه‌ها تمام‌عرض |
| `≤480px` | فشرده‌سازی فاصله‌ها و دکمه‌های تمام‌عرض |

نکات دیگر: پشتیبانی از `prefers-reduced-motion`، حالت چاپ، لینک پرش به محتوا،
و استایل `focus-visible` برای دسترسی‌پذیری.

## جایگزینی تصاویر

فایل‌های داخل `assets/img/` پلیس‌هولدر هستند. کافی است عکس‌های واقعی را با همان
نام (یا با به‌روزرسانی مسیر در `index.html`) جایگزین کنید:

| فایل | کاربرد | نسبت پیشنهادی |
|---|---|---|
| `portrait-hero` | تصویر هیرو | ۵:۶ |
| `portrait-about` | تصویر بخش درباره من | ۴:۴٫۴ |
| `course-1..3` | کاور دوره‌ها | ۱۶:۱۰ |
| `post-main`, `post-1`, `post-2` | کاور مقالات | ۱۶:۹ |
| `avatar-1..3` | آواتار نظرات | ۱:۱ |

فونت از Google Fonts (Vazirmatn) بارگذاری می‌شود؛ برای اجرای آفلاین می‌توانید
فونت را به‌صورت محلی اضافه کنید.
