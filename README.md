# قالب وردپرس تکراتو

قالب اختصاصی وردپرس برای سایت خبری-تکنولوژی **تکراتو**، ساخته‌شده بر اساس طرح فیگما (هوم‌پیج، صفحه دسته‌بندی و صفحه تک‌خبر). تم تیره، لهجه رنگی فیروزه‌ای، راست‌چین و کاملاً فارسی.

فایل نصبی آماده: **`techrato-theme.zip`** (در ریشه همین ریپازیتوری) — همین فایل را روی وردپرس آپلود کنید.
کد کامل قالب هم در پوشه‌ی `techrato/` موجود است.

## نصب روی هاست واقعی شما

1. وارد پیشخوان وردپرس شوید.
2. مسیر **Appearance ← Themes ← Add New ← Upload Theme**.
3. فایل `techrato-theme.zip` را انتخاب و **Install Now** بزنید، بعد **Activate** کنید.

(اگر این روش کار نکرد یا حجم فایل برای سرور بزرگ بود: از cPanel یا FTP وارد شوید، وارد پوشه `wp-content/themes/` شوید، فایل zip را آنجا آپلود و Extract کنید — نتیجه یکسان است.)

## بعد از فعال‌سازی — این چند قدم را انجام دهید

1. **منوها را بسازید:** مسیر Appearance ← Menus. چهار محل منو در قالب تعریف شده:
   - «منوی اصلی» (نوار بالای هدر)
   - «نوار پرطرفدارها» (نوار باریک زیر منو)
   - «فوتر - تکراتو» و «فوتر - دسته‌بندی‌ها» (ستون‌های فوتر)
   تا وقتی منو نسازید، قالب خودش آیتم‌های پیش‌فرض نمونه را نشان می‌دهد تا صفحه خراب دیده نشود.

2. **لوگو:** Appearance ← Customize ← Site Identity ← Logo. اگر لوگو تنظیم نکنید، به‌صورت پیش‌فرض نام سایت + آیکون تکراتو نمایش داده می‌شود.

3. **تنظیمات اختصاصی تکراتو:** Appearance ← Customize ← «تنظیمات تکراتو» شامل:
   - لینک‌های شبکه‌های اجتماعی (۳ آیکون بنر «مارا دنبال کنید»)
   - متن باکس خبرنامه فوتر
   - متن بنر «مارا در شبکه‌های اجتماعی دنبال کنید»

4. **دسته‌بندی‌ها را بسازید.** برای این‌که بخش‌های صفحه اصلی (پیشنهاد سردبیر، اخبار ایران، هوش مصنوعی، خودرو، کسب‌وکار و...) به‌درستی محتوای مرتبط نشان دهند، پیشنهاد می‌کنم دسته‌بندی‌هایی با این نامک‌ها (slug) بسازید:

   | نام دسته | Slug |
   |---|---|
   | تکنولوژی | `technology` |
   | هوش مصنوعی | `ai` |
   | خودرو | `car` |
   | کسب و کار | `business` |
   | آموزش | `learning` |
   | اپل | `apple` |

   اگر این دسته‌ها را نسازید، قالب خراب نمی‌شود — به‌جای آن، جدیدترین مطالب سایت را نشان می‌دهد تا صفحه هیچ‌وقت خالی نماند.

5. **مطلب منتشر کنید** و برای هر پست حتماً «تصویر شاخص» (Featured Image) تنظیم کنید تا کارت‌ها مثل طرح فیگما نمایش داده شوند.

## نکاتی که باید بدانید (محدودیت‌های فعلی)

- تب‌های دسته‌بندی («همه، اپل، موبایل، ...») فعلاً فقط ظاهری‌اند و به فیلتر واقعی وصل نیستند؛ در آینده می‌توانیم آن‌ها را به فیلتر AJAX واقعی وصل کنیم.
- فرم خبرنامه فوتر رابط کاربری آماده دارد ولی برای اتصال واقعی به سرویس ایمیل‌مارکتینگ (میلرلایت/میلچیمپ و…) باید آدرس فرم را در تنظیمات کاستومایزر وارد کنید.
- چون در محیط توسعه فعلی امکان نصب وردپرس واقعی وجود نداشت، قالب با یک هارنس تست شبیه‌سازی‌شده (stub) و رندر HTML واقعی بررسی و از نظر بصری با اسکرین‌شات مقایسه شد. اگر بعد از نصب روی سایت واقعی جایی خراب بود یا با طرح فرق داشت، بگویید تا سریع اصلاح کنم.

## ساختار پوشه‌ها

```
techrato/
├── style.css              → همه استایل‌ها + هدر معرفی قالب
├── functions.php          → راه‌اندازی قالب، منوها، اسکریپت/استایل‌ها
├── header.php / footer.php
├── front-page.php         → صفحه اصلی
├── category.php / archive.php / index.php / search.php → لیست مطالب
├── single.php              → صفحه تک‌خبر
├── page.php / 404.php / comments.php / searchform.php
├── inc/
│   ├── customizer.php     → تنظیمات Customize
│   └── template-tags.php  → توابع کمکی (زمان نسبی، بردکرامب، کوئری‌ها)
├── template-parts/         → قطعات قابل‌استفاده‌مجدد (کارت‌ها، بنر شبکه اجتماعی، ...)
└── assets/js/main.js       → منوی موبایل، تاگل روشن/تیره، تب‌ها
```
