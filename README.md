# دردونه · صفحهٔ اصلی با سبک «3D Immersive»

همراه رایگان خانواده‌های ایرانی؛ سلامت با تأیید پزشک، قصه‌ساز شخصی و لالایی شب.
زبان فارسی، راست‌به‌چپ، موبایل‌اول.

## اجرا

```bash
npm install
npm run dev       # توسعه روی http://localhost:5173
npm run build     # خروجی تولید در dist/
npm run preview   # پیش‌نمایش خروجی تولید
```

برای ارسال واقعی شمارهٔ موبایل، آدرس API را در `.env` بگذارید:

```
VITE_SIGNUP_URL=https://example.com/api/signup
```

تا وقتی این متغیر خالی است، فرم موفقیت را شبیه‌سازی می‌کند.

## کانسپت بصری: «گهوارهٔ ماه»

«دردونه» یعنی مروارید، یعنی عزیزِ دل. صحنهٔ سه‌بعدی اصلی یک هلال ماه به شکل گهواره است که مرواریدی در آن آرام گرفته، زیر آسمان شب و پشت تپه‌ها. هلال یعنی شب و لالایی، مروارید یعنی بچه، گهواره یعنی مراقبت؛ هر سه همان چیزهایی هستند که سایت ارائه می‌دهد. سه‌بعدی فقط در جایی آمده که به داستان کمک می‌کند:

| بخش | عنصر سه‌بعدی | فناوری |
|---|---|---|
| Hero | گهوارهٔ ماه و مروارید، سه سطح عمق | three.js (بارگذاری تنبل) |
| مزیت‌ها | آیکن‌های برجسته با پرسپکتیو و Hover | CSS |
| معرفی محصول | گوشی قابل چرخش با نقاط راهنما | CSS 3D |
| گالری | پارالاکس لایه‌ای جلدها | SVG و CSS |
| فراخوان نهایی | مروارید در گهواره | CSS |

## ساختار صفحه

1. **هدر ثابت**: لوگو، پنج لینک با وضعیت فعال (رنگ + خط زیر)، دکمهٔ «شروع رایگان»، منوی موبایل با Escape و حلقهٔ فوکوس.
2. **Hero**: یک `h1`، توضیح دو خطی، یک دکمهٔ اصلی و یک ثانویه، صحنهٔ سه‌بعدی. متن و دکمه‌ها HTML واقعی‌اند.
3. **چرا دردونه**: چهار مزیت.
4. **امکانات**: گوشی سه‌بعدی با سه نما (زبانه‌ها) و نقاط راهنمای شماره‌دار. با موس، لمس و کلیدهای جهت می‌چرخد.
5. **نحوهٔ کار**: چهار قدم روی یک مسیر پیوسته که هم‌پای اسکرول پر می‌شود.
6. **قصه و لالایی**: گالری بدون حرکت خودکار، نمای جزئیات در `dialog` با دکمه‌های قبلی و بعدی.
7. **پزشکان و کاربران**: جای خالی مشخص برای نام پزشکان و نظر کاربران؛ هیچ نام، آمار یا نظری ساختگی نیست.
8. **فراخوان نهایی**: یک پیام، یک فرم کوتاه، یک دکمه.
9. **فوتر**: لینک‌ها، تماس (جای خالی)، شبکه‌های اجتماعی، حریم خصوصی، شرایط استفاده، سلب مسئولیت پزشکی.

## توکن‌های طراحی

همهٔ مقادیر در `src/styles/tokens.css` تعریف شده‌اند.

- **رنگ اصلی**: فیروزه‌ای `#1F5F63`
- **رنگ تأکیدی**: مهتاب `#F0C766`؛ فقط برای کنش اصلی و ماه
- **خنثی‌ها**: سرمه‌ای شب (`#111A2C`، نه مشکی مطلق) و خاکستری متمایل به فیروزه‌ای
- **کنتراست**: همهٔ جفت‌های متن و زمینه AA هستند؛ عدد هر کدام کنار توکن نوشته شده
- **فونت**: فقط Vazirmatn متغیر، از بستهٔ `@fontsource-variable/vazirmatn` و بدون وابستگی به سرور خارجی. اندازه‌ها با `clamp` بین موبایل و دسکتاپ؛ متن بدنه ۱۶ پیکسل.
- **فاصله**: پایهٔ ۴ و ۸ (`--sp-1` تا `--sp-10`)
- **شعاع**: ۱۲، ۲۰، ۳۲ و کاملاً گرد
- **سایه**: سه سطح (`--shadow-1` تا `--shadow-3`) و یک سایهٔ شب
- **حرکت**: ۱۵۰، ۲۵۰ و ۴۰۰ میلی‌ثانیه
- **نقاط شکست**: ۳۷۵، ۷۶۸، ۱۰۲۴، ۱۴۴۰

## رفتار صحنهٔ سه‌بعدی

- **بارگذاری**: پوستر WebP (حدود ۱۰ کیلوبایت) فوراً نمایش داده می‌شود. three.js بعد از رندر اولیه و در زمان بیکاری مرورگر، به‌صورت جداگانه بارگذاری می‌شود و تیتر و دکمه را مسدود نمی‌کند.
- **هندسه**: همهٔ مدل‌ها در کد ساخته می‌شوند. هیچ فایل مدل یا تکسچری دانلود نمی‌شود؛ برای همین GLB/Draco لازم نشد.
- **نور**: یک نور کلیدی گرم، یک نور لبهٔ سرد، نور محیطی آسمان و زمین، و یک محیط بازتاب کم‌حجم برای مروارید. سایهٔ بلادرنگ ندارد.
- **حرکت**: یک تکان آرام اولیه برای گهواره (یک بار، ۲٫۴ ثانیه). بعد از آن فقط با نشانگر (دوربین حداکثر ۰٫۲۵ واحد، گهواره حداکثر ۷ درجه) و با اسکرول (پارالاکس سه سطح) حرکت می‌کند. حلقهٔ انیمیشن دائمی ندارد و فقط وقتی چیزی تغییر کند رندر می‌کند.
- **صرفه‌جویی**: بیرون از دید یا در تب غیرفعال، رندر متوقف است.
- **توان دستگاه** (`src/hooks/deviceTier.js`):
  - بدون WebGL، حالت صرفه‌جویی داده، دستگاه ضعیف یا عرض کمتر از ۳۶۰ پیکسل: فقط پوستر ثابت
  - موبایل و تبلت: هندسهٔ ساده‌تر و نرخ پیکسل حداکثر ۱٫۵
  - دسکتاپ: نرخ پیکسل حداکثر ۲
- **کاهش حرکت**: با `prefers-reduced-motion`، تکان اولیه، پارالاکس، چرخش با نشانگر، چرخش گوشی و پر شدن مسیر اسکرولی حذف می‌شوند و همه‌چیز در حالت نهایی نمایش داده می‌شود.
- **معادل متنی**: صحنه یک `figcaption` توصیفی برای صفحه‌خوان دارد و خود canvas از صفحه‌خوان پنهان است.

برای ساختن دوبارهٔ پوستر بعد از تغییر صحنه، `npm run dev` را اجرا کنید، `scripts/poster-harness.html` را در مرورگر باز کنید و از قاب ۹۰۰ در ۱۰۰۰ پیکسل عکس بگیرید. نسخهٔ WebP آن را در `public/hero-poster.webp` بگذارید.

## وضعیت‌های تعاملی

- **دکمه‌ها**: Hover، Active (فشرده شدن)، Focus (حلقهٔ دو رنگ)، Disabled
- **لینک‌های منو**: Hover، فعال (رنگ + خط زیر، `aria-current`)
- **زبانه‌ها**: کلیدهای جهت (در راست‌به‌چپ، چپ یعنی بعدی)، Home و End
- **نقاط راهنما**: Hover، Focus و کلیک، هم‌زمان روی فهرست و روی گوشی
- **فرم**: خطای اعتبارسنجی با متن و آیکن (`aria-invalid` و `role="alert"`)، در حال فرستادن، موفقیت، خطای شبکه. اعداد فارسی و عربی و پیشوند ‎+98 پذیرفته می‌شوند.
- **گالری**: باز شدن با کلیک یا Enter، بستن با Escape یا کلیک بیرون، بازگشت فوکوس به کارت

```
index.html                 عنوان، توضیح، Open Graph، پیش‌بارگذاری پوستر
public/                    پوستر صحنه، تصویر Open Graph، فاوآیکن
scripts/                   ابزار ساخت پوستر و تصویر Open Graph
src/
  main.jsx                 نقطهٔ شروع
  App.jsx                  ترتیب بخش‌ها
  data/content.js          همهٔ متن‌ها و جاهای خالی
  styles/tokens.css        توکن‌های طراحی
  styles/base.css          پایه، دکمه‌ها، دسترس‌پذیری
  scene/heroScene.js       صحنهٔ three.js
  hooks/                   کاهش حرکت، توان دستگاه، بخش فعال، دیده شدن
  components/              هر بخش با CSS جدای خودش
```
